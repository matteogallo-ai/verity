# Verity 1.1.0

This file describes the `[1.1.0]` section of `CHANGELOG.md`.
Each figure below is copied from the committed artefact named next to it.
The README, `docs/results.md` and the system card render the same figures from those
files, and CI checks that they match.

## The run of record

One live run of the shipped defaults on the held-out test split:
`datasets/eval/runs/live/eval_513b839_test.incomplete-20261107T122042441670Z.json`.

- **Configuration.** Agent `claude-sonnet-4-6`, judge `claude-opus-5-5` with judge
  prompt v0.2.0, `synthesize.prompt` v0.3.0 (datamarked evidence), confidence threshold
  0 and the cited-relevance check off.
- **Completeness.** 54 of the 56 questions ran before the run's $2.40 spending cap
  stopped it. The other 2 were never asked. They are not counted as errors, and the
  metrics leave them out.
- **Scorecard:** `scorecards/live-v1.1.0.json`, schema v6.

## What changes for a reader of the numbers

- **The headline counts every invented answer.** "Invented answers" is computed over
  every judged answer, answerable or not: 1/40, Wilson 95 % [0.004, 0.129]
  (`q-089`). The earlier headline, the hallucination rate on answerable questions only,
  excluded by definition the one real invention of the previous test run (`q-074`).
  - On this run, that answerable-only rate is 0/35.
  - Both rates are published, each with its definition
    (`docs/evaluation-methodology.md`).
- **Refusal.** Refusal recall 13/18, [0.491, 0.875], at refusal precision 13/14,
  [0.685, 0.987]. 5 of 18 out-of-scope questions were answered.
- **Verity against a naive RAG baseline, pre-registered with a power analysis.** The run
  covers all 95 questions, of which 93 were completed by both arms
  (`scorecards/two-arm-comparison.json`,
  `docs/preregistration/two-arm-comparison.md`). Each outcome is tested with an exact
  McNemar test, Holm-adjusted over three primary outcomes. A self-abstention counts as
  a refusal.
  - **Unanswerable answered:** Verity 4/31, naive 12/31. The 8 discordant questions
    were all answered by the naive arm only: p 0.0078, Holm 0.0234.
  - **Answerable answered:** 58/62 against 62/62. Holm p 0.25, not measurable at this n.
  - **Invented answer:** 0/93 against 3/93. Holm p 0.25, not measurable at this n.
    Here a self-abstention counts as a refusal, so `q-089`, a self-abstention with an
    unsupported claim and the 1 of the headline's 1/40, is not counted; without that
    rule it is 1/93 against 5/93.
- **Correctness against the reference answers.** This grade is separate from
  faithfulness. On the answerable questions the run of record answered: 35/35 correct
  (`scorecards/correctness.json`). The grade is not validated against human labels.
- **The judge is named with its own validation.** Judge prompt v0.2.0 has κ 0.60 against
  blind human labels, on 52 of 60 claims; its rejudge stopped at its spending cap. The
  κ of prompt v0.1.0 (0.71, bootstrap 95 % [0.49, 0.89], on 60 claims of which 1 real
  hallucination) is no longer used for runs judged by another prompt.
- **Refusal checks one at a time** (`scorecards/gate-ablation.json`). This replays the
  checks on the runs already committed, with no model call. On dev, the cited-relevance
  check made more wrong refusals than right ones, so it is off by default. The
  confidence threshold defaults to 0, which refuses nothing.
- **Error SLO.** The SLO counts as met only when its Wilson upper bound is: 0/54,
  "no violation observed; n too small to conclude".
- **Cost per query:** $0.0235 for the agent only, $0.0455 with the judge.

## Security

- **Retrieval errors.** A defect in a retrieval stage now propagates as a defect. The
  agent types it `INTERNAL`, and the API answers a generic 500 and still charges what
  the request paid for. It is no longer reported as "store down" (503).
- **Pinned images.** Container images are pinned by digest, Dependabot tracks the Docker
  and Compose digests, and no workflow checkout keeps its token.
- **Reporting channel.** `SECURITY.md` names one channel: GitHub private vulnerability
  reporting.
- **Known advisories.** minimatch 11.0.5 replaces 10.2.6 in the lint toolchain. The
  accelerate advisory (GHSA-4j2p-28q2-5m79) has no fixed release; it stays an accepted
  exception in `osv-scanner.toml` because neither Verity nor any installed package calls
  the two vulnerable checkpoint loaders, which `tests/unit/test_osv_exceptions.py` checks.

## What the numbers do not say

- **No full-corpus baseline.** The full-corpus baseline (the whole 5,489-word corpus in
  the prompt) is specified but not run. Its measured cost, about $20 for 95 questions,
  is in the pre-registration.
- **The judge's family.** The corpus and the questions were written with a model of the
  judge's family (`datasets/CORPUS.md`). No second judge family and no second human
  annotator exist (C34, roadmap).
- **Calibration.** The confidence score is the scorer model's self-report. Its
  calibration is not shown (C21, roadmap).

## Upgrading

- **Defaults.** `VERITY_CONFIDENCE_THRESHOLD` defaults to 0.0, and
  `VERITY_IRRELEVANT_CITATION_CHECK` defaults to false. Set either one to restore the
  1.0 behaviour.
- **SDK.** The Anthropic SDK is 2.x and no sampling parameter is sent. A pinned 1.x
  environment needs `uv sync`.
- **Scorecard schema.** The headline scorecard schema is v6, which adds
  `answer_quality.invented_answer_rate`, `cost.per_query_with_judge_usd` and
  `sample_sizes.n_not_run`. The generators refuse older schemas.
